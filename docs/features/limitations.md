# Limitations

- The [Hotkey](hotkey.md) can't be changed.
- Only the primary display is used.
- Splits are 50/50 and can't be resized; see [Tabs and Panes](tabs-and-panes.md).
- The Tab bar can't be clicked.
- The installed app registers itself as a login item every time it starts.
- [Restore](restore.md) doesn't re-run each Pane's last command.
