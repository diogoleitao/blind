# blind documentation

What blind can do, how to set it up the way you like, and how to use it day to day. Terms such as Session, Tab and Pane are defined in [`GLOSSARY.md`](../GLOSSARY.md).

## Usage

- [Getting started](usage/getting-started.md): bring blind down with the Hotkey, name a first Session, split a Pane, open the Command Palette and hide blind again.
- [One Session per project](usage/one-session-per-project.md): name a Session, set its Root directory, open one per project and switch between them.
- [Leaving programs running](usage/leaving-programs-running.md): close a Session or quit blind while claude or a build runs, come back to its output, and end it when you want it gone.
- [Following Activity](usage/following-activity.md): find out when Claude Code finishes in another Session, from the Tab bar, the Activity Sidebar and the Activity Sound.

## Features

- [Hotkey](features/hotkey.md): bring blind down over every app on one key, and keep it out of the Dock and `Cmd+Tab`.
- [Sessions](features/sessions.md): one Session per project, named or not, cycled through, closed and reopened, or deleted.
- [Shells that outlive the app](features/shells-outlive-the-app.md): quit blind and every program keeps running, held by Blind Spot.
- [Restore](features/restore.md): every Session comes back with its Tabs, splits, working directories and scrollback.
- [Tabs and Panes](features/tabs-and-panes.md): Tabs, nested splits, titles, start directories and closing.
- [Hidden Tabs](features/hidden-tabs.md): take a Tab out of the Tab bar without closing it.
- [Command Palette](features/command-palette.md): search every Session, Tab, Pane and action with `Cmd+K`.
- [Activity](features/activity.md): see which Panes want your attention, and list them in the Activity Sidebar.
- [Inside a Pane](features/inside-a-pane.md): clickable links, Find in Pane and terminal identity.
- [Appearance](features/appearance.md): Themes, importing them from other terminals, and see-through windows.
- [Menu Bar Icon](features/menu-bar-icon.md): every Session one click away from the menu bar.
- [Show Build](features/show-build.md): the version and commit blind and Blind Spot are running.
- [Limitations](features/limitations.md): what blind can't do yet.
